# Public Prompt Templates

This directory contains publication-safe prompt templates for producing A4V3
entries. They are provider-neutral and do not include private agent
orchestration code, API configuration, local paths, or experiment logs.

The private research workspace may contain richer multi-agent prompts and
repair loops. Those are not part of this public toolkit. The template here is a
minimal reproducible baseline that can be used with any LLM client.
