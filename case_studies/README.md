# Case Studies

This directory contains curated, publication-safe case studies for the A4V3 IR
toolkit.

## Available Packages

- `financial_methodology/` - a cleaned 55-fragment financial index methodology
  package with local A4V3 entries, bridge/merge layers, target projections, and
  reasoning reports. Original source text is not redistributed.

The case studies are intentionally curated. Draft translations, temporary agent
runs, private source text, local machine paths, and exploratory transcripts are
excluded unless a file is explicitly needed as a public artifact.
